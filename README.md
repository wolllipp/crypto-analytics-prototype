# Crypto Analytics — интерактивный прототип

Открыть: https://wolllipp.github.io/crypto-analytics-prototype/ · десктоп и телефон рядом: [preview.html](https://wolllipp.github.io/crypto-analytics-prototype/preview.html)

Разделы: **Главная** (кошельки только на просмотр, цена BTC за сутки, 4 действия, сумма в пределах лимита, новости) · **Рынок** (диапазон на неделю, сценарии, индекс страха и жадности, 20 монет) · **Журнал** · «Спросить».

Путь новичка: «Попробовать без денег» (песочница, без почты и согласий) → «Посчитать» → записать решение → итог недели сразу. Реальный режим: 3 шага (баланс → лимит → почта). Страна и согласия — только перед переходом на биржу-партнёр; сумма плана подставляется в форму биржи. Пример с историей для показа — Профиль → Демо. План редизайна: `docs/redesign-plan-2026-10-20.md`.

Разметка готовится к переносу в React Native (Expo): повторяющиеся компоненты, токены в `:root` в `styles.css`, раскладка только flex, без опоры на hover. Ассистент в микрофоне отвечает на вопросы, но не говорит, вырастет или упадёт цена.

Цифры иллюстративные. Ассистент без ключа работает в демо-режиме; ключ OpenRouter вводится в Настройках и хранится только в браузере. Для общей ссылки — прокси `proxy-worker.js`.
